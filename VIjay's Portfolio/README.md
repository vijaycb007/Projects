### 🤟 Hands2Speech
> Real-time sign language to text and speech translator — built to bridge communication for the hearing-impaired.

*Note: Dataset not included — model scripts only.*

**Stack:** Python · OpenCV · MediaPipe · TensorFlow/Keras · BiLSTM · NumPy · HTML · CSS ·JavaScript
